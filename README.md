# Funngro 2-Page Website Revamp

A React + Vite evaluation-project redesign with:

- Company landing page: `/`
- Teen opportunity page: `/teen`
- Responsive mobile/desktop UI
- SEO meta title, description, keywords and Open Graph tags
- Semantic headings, links, FAQ details and accessible labels
- No external image dependency; visuals are CSS-based

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

1. Push this project to GitHub.
2. Open Vercel and import the repository.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.
7. Copy the live URL and paste it in Funngro's Remarks field.

## Important

This is an evaluation redesign concept. Replace placeholder email/contact details before using it for a real business. Do not copy proprietary logos, images or text from the original website without permission.
